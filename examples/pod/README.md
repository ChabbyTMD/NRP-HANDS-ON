# NRP Pod Examples.

This directory contains the "Hello World" pod and a simple pod recipe that writes data to the `cephfs-pvc-sdsu-sethuraman-lab` PVC.

> Note: Don't forget to change the `<username>` placeholder with a username of your choice i.e. one word no spaces e.g. `tmugoya`. This is important to avoid naming conflicts with other pods in the namespace.
